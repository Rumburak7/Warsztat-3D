# Warsztat 3D

**Autor: Adam Bryks, 2026**

Własny program do projektowania modeli do druku 3D: szablony (obudowy na ESP32, szufladki, formy do odlewów…),
budowanie z klocków jak w Tinkercad, czas i koszt druku, test luzu drukarki, przecinanie dużych części,
pliki STL i 3MF, Magazyn obiektów 3D z projektami i zdjęciami.

Program działa w przeglądarce Chrome / Edge na komputerze. Projekty zapisują się w wybranym folderze na dysku
(albo w przeglądarce). Nic nie jest wysyłane do internetu.

Wersja na GitHub Pages – ten sam program co na ESP32-S3 z kartą SD.
